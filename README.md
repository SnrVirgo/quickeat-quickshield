# QuickEat QuickShield (Fabric, Minecraft 26.3, client-side)

Right click once and the mod holds the button for you:

- Food: eats ONE item, then stops.
- Shield: stays raised. Right click again (or left click) to lower it.
- Bow: stays drawn. The next right click releases it = shoots.
- Crossbow: charges by itself and gets loaded. The next right click shoots.
- Food in the main hand has priority over a shield in the off hand (vanilla main-hand-first rule).
- Opening any screen (inventory, chat) stops it.

Build: push to GitHub -> Actions tab -> "build" -> download the jar from Artifacts.
